# CRJ Chrochet

Clean Next.js application foundation using the current stable toolchain.

## Stack

- Next.js 16.4.0
- React 19.3.0
- TypeScript 7.0.2
- Tailwind CSS 4.3.3
- shadcn CLI 4.21.1
- App Router
- ESLint 10

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## shadcn/ui

The project is initialized for shadcn/ui and includes the button component as the first registry component.

```bash
npm run ui -- add card
```
