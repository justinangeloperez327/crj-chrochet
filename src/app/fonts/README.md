# Bundled fonts

Latin variable WOFF2 subsets from Fontsource packages version 5.3.0:
- `@fontsource-variable/fraunces` — display headings (weight axis).
- `@fontsource-variable/geist` — interface and body text.
- `@fontsource-variable/geist-mono` — code and tabular utility text.

Each font's SIL Open Font License is included alongside it. Keep these notices when redistributing. Loaded with `next/font/local`; no font download is needed during builds.
